---
description: 実装担当を並列に動かし、TODO・FAIL の項目を一気に潰す
---

`docs/CHECKS.md` で状態が `TODO` または `FAIL` の項目を担当ごとにまとめ、該当する実装担当（`.claude/agents/*-engineer.md`）を**同時に**起動してください（1つのメッセージで複数の Agent 呼び出しを出す）。

各エージェントへの指示に含めること:
- 担当する項目IDの一覧と、`docs/CHECKS.md` の該当行
- 持ち場以外は編集しないこと。共有の層や型の変更が必要なら、止めて報告すること
- 終わったら、通したID・残りのID・必要な共有層の変更を報告すること

全員が戻ったら:
1. 報告の「必要な共有層の変更」をリードとして反映する。
2. `grader` サブエージェントで検証し、`docs/CHECKS.md` を更新する。
3. まだ落ちている項目があれば、この手順をもう一周する。後退（前回 PASS→今回 FAIL）があれば最優先で直す。
4. 区切りごとに、意味のある単位で git commit する。
